# Knova - Coding Community Platform

<p align="center">
  <img src="public/images/logo.png" alt="Knova Logo" width="200" />
</p>

Knova is a modern platform designed for developers to learn, debug, and grow together. It provides a collaborative environment where coders can connect with experts, participate in live debugging sessions, and get their coding doubts resolved.

## 🚀 Features

- **Expert Connect**: Connect with experienced developers for personalized help
- **Live Debugging Sessions**: Join or host real-time debugging sessions
- **Token System**: Purchase tokens to access premium features and expert sessions
- **Community Interaction**: Post questions and get answers from the community
- **Responsive Design**: Fully responsive UI that works on all devices

## 📋 Pages

- **Landing Page**: Introduction to Knova with key features
- **Dashboard**: User's personalized dashboard with latest questions and activities
- **Expert Connect**: Find and connect with coding experts
- **Debug Session**: Interactive debugging environment with code editor and video streaming
- **Pricing**: Token packages and payment options

## 🛠️ Tech Stack

- **Frontend**: Next.js 14 with App Router
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Geist Font (Sans & Mono)



## 🚦 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

Clone the repository:
   ```bash
   git clone https://github.com/yourusername/knova.git
   cd knova

npm install
# or
yarn install

npm run dev
# or
yarn dev
```

Open http://localhost:3000 with your browser to see the result.

## 🧩 Components
### Dashboard Components
- Sidebar : Navigation menu for the application
- LatestQuestions : Display of recent questions from the community
- FeaturedExperts : Showcase of top experts on the platform
- LiveDebuggingSessions : Current active debugging sessions
- RecentActivity : Recent user activities on the platform
### Expert Connect Components
- ExpertsList : Grid display of available experts with filtering options
- LiveAvailability : Real-time status of expert availability
### Debug Session Components
- CodeEditor : Interactive code editor for debugging
- VideoStream : Video communication during debugging sessions
- ChatInterface : Text-based communication
- IssueTracker : Track and manage issues during debugging
## 🔄 State Management
The application uses React's built-in state management with hooks for component-level state.
